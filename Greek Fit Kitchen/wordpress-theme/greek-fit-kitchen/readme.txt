Next-generation healthy meal preparation and scheduled delivery WordPress theme for Greek Fit Kitchen.

== Description ==

Greek Fit Kitchen is an ultra-fast, modern WordPress theme designed specifically for scheduled meal-prep and advance delivery services.

Key Features:
* Fully Editable with Elementor (Widgets for Hero Slider, Meals, Plans, How It Works, Calculator)
* Advance Scheduled Delivery (Sunday & Wednesday cutoff management)
* 6-Meal Starter Package check ($59.94 CAD minimum)
* 10% Volume Discount automated calculation for 7+ meals
* 2 Included Sides customizer per dish (11 gourmet side choices)
* Interactive Distance-Based Delivery Calculator ($5.99 + $0.99/km)
* Kitchen Tablet Display System (KDS) for kitchen prep staff
* Light / Dark Theme Switcher with localStorage persistence

== Installation ==

1. In your WordPress Admin, go to Appearance > Themes > Add New.
2. Click "Upload Theme" and choose `greek-fit-kitchen.zip`.
3. Click "Install Now" and then "Activate".
4. Go to Pages > Add New, name it "Home", and click "Edit with Elementor" or use the default Front Page.
5. Create a page with the "Kitchen Display Tablet" template for your kitchen staff.
